# BESS SAP S/4HANA UI images

本套图展示 BESS-DE-2401 Hafen-West 储能电站项目（50 MW / 100 MWh）的 EPC 建设、项目财务与后续维护业务，按原需求编号 01–12。

生成方式：GPT Image。图片采用统一的 SAP Horizon 风格应用外壳与 GUI for HTML 布局，图片内不添加“模拟界面”文字。它们是根据示例业务与事务代码生成的界面图，未从运行中的 SAP 系统截取，也未验证特定最新发行版本的所有控件。实际界面、字段及可用事务取决于版本、部署方式和客户配置。

## 业务示例

- 项目：BESS-DE-2401；公司代码 DE01；控制范围 1000；工厂 DE10；币种 EUR。
- 原始预算 EUR 12,000,000；实际成本 EUR 6,000,000；承诺 EUR 2,000,000；已分配 EUR 8,000,000；可用 EUR 4,000,000。
- 基准合同收入 EUR 15,000,000；预测总成本 EUR 10,000,000；成本法 POC 60%；累计确认收入 EUR 9,000,000；累计开票 EUR 10,500,000；合同负债 EUR 1,500,000。
- 施工实体进度与成本法 POC 分开理解。报告 CPR-2026-09-001 日期为 30.09.2026。
- 服务阶段设为 2027 年：设备 10000051、维护计划 90000123、服务合同 50000123、服务订单 80000456。
- 第 12 张是单独的 REV-02 亏损预测情景：预测总成本 EUR 16,000,000，成本法 POC 37.5%，累计收入 EUR 5,625,000，累计合同负债 EUR 4,875,000。它不是在第 8 张凭证之上重复过账的第二张完整凭证。

## 事务与适用性

1. CN41N 为项目结构/信息系统视图，CJ20N 为 Project Builder。图 01 以 CN41N 层级列表为主要布局。
2. CJ30 维护原始预算，CJ31 显示预算，CJ32 释放预算。图 02 以 CJ31 为主要布局；AVC 摘要、列及利用率显示属于业务示例布局，依赖客户预算参数和配置。
3. /SAPPCE/PNV08、/SAPPCE/PNV09 是历史工程建设进度报告事务。公开的 S/4HANA 1511 简化项副本曾说明相关功能不适用于该版本，不能据此断言当前最新版本仍标准交付。图 03/04 作为保留事务号的历史兼容/客户扩展示例；Excel 导入按钮、报告列及进度汇总未被确认是最新标准 SAP 功能。
4. 图 05 的 CJE0 报表 ZBESS_COST_REV 是客户报表示例，不能作为 SAP 标准报表定义。
5. 图 06 使用 CN25 的网络活动确认业务。网络 40001234 / 活动 0020 为部分确认，当前录入 160 H；累计工时 960 H，预测总工时 1,600 H，剩余 640 H。12/20 台容器与该活动 60% 的实体完成度一致。
6. KKA2 计算、保存结果分析；CJ88 执行结算及相应 FI 过账。图 07 与图 08 的计算/过账职责分开。实际结果分析方法、RA key、行标识、结算结构与科目映射由客户配置决定。
7. 图 08 的 FI 示例凭证 1900008421 为 EUR 1,500,000 的收入调整与合同负债对平。EUR 6,000,000 成本结算另行展示，不与该两行收入调整重复相加。
8. 图 09 以 IP02 维护计划为主视图。VA41 创建 SD 服务合同；IP01/IP02 创建/修改维护计划。图中的直接合同关联字段代表客户集成/扩展，并非所有版本的标准 IP02 字段或自动关联。
9. 图 10 以 IW32 订单执行为主，IW31/IW33 分别对应创建/显示。计划工时 16 H、实际 12 H，订单为 REL PCNF。
10. 图 11 以 IE03 设备显示为主，并引用物料。服务履历弹窗代表将 IW39 查询结果整合到设备视图的客户布局；IE03 不能等同于通用产品主数据维护。
11. 第 12 张仍是 KKA2/经典 PS 结果分析示例，结算状态为待执行。预计总亏损 EUR 1,000,000，其中已体现亏损 EUR 375,000，剩余预计亏损准备 EUR 625,000。累计开票与累计收入的差额为 EUR 4,875,000；后续结算应按已过账累计额计算差额，不能重复过账全额。
12. Revenue Accounting / RAR 是独立收入会计流程。“RR”在原需求中作为模块方向保留，不作为已验证的具体事务代码；本套图不宣称 KKA2/CJ88 取代所有 RAR 流程。
